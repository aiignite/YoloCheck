## 二、人体运动识别算法架构与设计

### 1. 算法技术路线
- **网络骨干**：采用 **YOLOv8-Pose / YOLO11-Pose**，兼具高速检测与 17 个骨骼关键点（COCO Keypoint 格式：鼻子、双眼、双耳、双肩、双肘、双腕、双髋、双膝、双踝）回归能力。
- **动作识别机制**：
  - **静态几何约束**：躯干俯仰角 $\alpha = \arccos(\frac{\vec{v}_{torso} \cdot \vec{e}_z}{\|\vec{v}_{torso}\|})$，双肘弯曲角 $\beta$，判定操作姿态规范性；
  - **动态时序滑窗**：采用长度 $T=30$ 帧（约 1 秒）的滑窗时序缓冲池，提取关键点运动速度向量 $V_t = P_t - P_{t-1}$ 与加速度特征。
- **业务输出**：
  - 工人入岗与离岗检测（有效工时统计）；
  - 防静电手环（ESD Strap）穿戴防呆；
  - 宏观工步触发（料盒取料、转身拿板、放板入仓）。

## 三、手部运动识别算法架构与设计

### 1. 算法技术路线
- **两阶段级联架构**：
  - **阶段一（手部区域引导）**：由人体姿态网络直接提供手腕关节点作为先验锚点，自适应动态截取 $224 \times 224$ 局部高清晰度 ROI，避免全图计算手部模型带来的显存与算力浪费。
  - **阶段二（21点指骨空间拓扑）**：针对工业手套环境微调的 YOLO-Hand 或 MediaPipe Industrial 模型，预测掌骨与指节 21 点空间三维拓扑向量。
- **细粒度微动判定**：
  - **Pinch/Pick（捏取）**：拇指指尖 (Id: 4) 与食指指尖 (Id: 8) 欧氏距离 $d_{pinch} < \delta_{thresh}$；
  - **Tool Manipulation（工具作业）**：手部包围盒与电批、点胶枪、镊子的交并比 (IoU) 及接触点相对稳定度判定；
  - **Component In-Place（插件到位）**：手部离开特定工位坐标瞬间，通过工件检测判定器件是否归位。

## 四、SMT 贴片质量识别算法架构与设计

### 1. 算法技术路线
- **网络骨干**：**YOLOv8-OBB (Oriented Bounding Box) 旋转目标检测**，带角度预测参数 $(x, y, w, h, \theta)$，专治密集引脚器件重叠及任意角度旋转贴装。
- **大图切片超分辨率推理 (SAHI)**：
  - 针对 2000 万至 5000 万像素高清 PCB 面阵图像，采用 $640 \times 640$ 动态网格滑窗切片（Overlap = 20%）；
  - 各切片局部并行推理后，通过 Global-NMS（全局非极大值抑制）消除边界冗余框，映射回整板空间坐标。
- **缺陷多类别识别矩阵**：
  | 缺陷类别 | 特征表象 | 判定准则与算法机制 |
  | :--- | :--- | :--- |
  | **元件偏位 (Shift)** | 贴片偏移焊盘 | 计算组件中心与设计焊盘基准偏移距离 $\Delta d > 0.05\text{mm}$ |
  | **角度偏转 (Skew)** | 旋转角度超标 | 旋转框主轴角度偏离焊盘法向夹角 $\Delta \theta > 3^\circ$ |
  | **立碑/吊桥 (Tombstone)** | 一端翘起悬空 | 焊端高光非对称性检测及阴影投射特征二值化分析 |
  | **桥接/连锡 (Bridging)** | 引脚间锡膏粘连 | 密集 pin 脚间区域局部语义分割 (Segmentation Mask) 连通域连通 |
  | **错件/漏贴 (Missing)** | 无器件或规格不符 | 丝印 ROI 文本 OCR 匹配或对比空焊盘特征响应分数 |

## 五、当前项目状态与功能差距深度分析

经过对当前前端平台 (`src/` 与 `temp_yolocheck/`) 的代码架构与算法落地深度比对，当前系统与工业生产全闭环之间存在以下具体差距：

| 功能维度 | 当前项目已有能力 (As-Is) | 生产级全能力需求 (To-Be) | 差距点 (Gap) |
| :--- | :--- | :--- | :--- |
| **1. 人的运动识别** | 前端预设了作业节拍统计、姿态展示与模拟指标。 | 接入实时 RTSP 视频流，在工控机端由 YOLOv8-Pose 实时推理输出 17 点骨骼，并做动作状态机状态转移。 | 缺少边缘 Python/C++ 推理节点；缺少 WebSocket/MQTT 关键点轨迹实时推流与前端 Canvas 动态骨骼骨架叠加渲染。 |
| **2. 手部运动识别** | `VideoLearningView` 支持工序片段管理、SOP 节拍设定、微步列表配置。 | 基于动态 ROI 的 21 关节手部细粒度追踪，精准判定“抓取、对准、插装、锁付”等亚秒级动作。 | 当前工步主要基于时间轴与模拟触发，缺少真实手势几何拓扑计算、手部与工具/元件的交互碰撞检测算法库。 |
| **3. SMT 贴片质检** | `VisionInspectorView` 支持多缺陷框标注高亮、置信度阈值过滤、缺陷统计与 `labels.txt` 导出。 | 支持 SAHI 超大图切片拼接；支持 OBB 旋转框展示与微米级物理公差计算；支持相机实时抓拍触发。 | 当前仅支持轴对齐矩形框 (AABB: $x, y, w, h$)，尚未支持带旋转角度的 OBB 渲染；未内置真实 SAHI 切片重组逻辑与工业相机驱动。 |
| **4. 数据集体检** | `DatasetCheckerTool` 实现了坐标越界、负坐标检测与一键 Auto-Clamp 钳位修复。 | 工业级全面体检：标签偏斜度、极小目标（<4像素）过滤、宽高比畸形检测、OBB 旋转标注校验、COCO/YOLO 互转。 | 仅覆盖了标准 YOLO 矩形格式，未覆盖 YOLO-OBB（5参数带角度）以及 Pose 格式的体检规则。 |
| **5. 边缘协同机制** | 前端界面完备（多路监控、MES 分析、训练评估、工单流转），具备完整交互与模拟器。 | 前后端全双工联动，边缘端具备 Python FastAPI/Triton/TensorRT 服务，支持配置双向下发与抓拍告警上报。 | 当前为单前端 Web 应用，需要提供边缘算法接入规范、RESTful/WebSocket 协议契约文档与后端桥接接口。 |

## 六、分阶段实施路径与升级方案

为弥合上述差距，制定以下四阶段工程实施方案：

### 阶段一：前端算法可视化与交互全能力增强 (本期推进)
1. **升级 `VisionInspectorView` 支持 OBB 旋转框与细粒度参数**：
   - 增加旋转框渲染支持，支持展示偏转角度 $\theta$、真实物理尺寸换算值（mm）；
   - 增加 SMT 缺陷类型专用过滤器与微米级公差合规判定器。
2. **升级 `VideoLearningView` 骨骼与手部交互实时模拟器**：
   - 引入 17 点人体骨架 + 21 点手部关键点的 Canvas 动态渲染；
   - 增加“拾取-装配-紧固”时序动作状态机模拟触发器，实时展示工步识别判定置信度。
3. **升级 `DatasetCheckerTool` 支持高级缺陷体检**：
   - 增加对 OBB 格式（包含角度）的语法体检与修复规则；
   - 增加极小目标检测与宽高比畸形警告。

### 阶段二：边缘推理服务协议与规范设计 (Edge Integration)
1. **标准化 WebSocket 协议**：
   - 制定 `/ws/live-stream` 与 `/ws/inferences` 协议，定义包含 `person_keypoints`、`hand_landmarks` 和 `smt_defects` 的统一 JSON Payload。
2. **边缘 Python 推理引擎脚手架**：
   - 提供基于 Ultralytics YOLOv8/YOLO11 的边缘部署脚本，结合 TensorRT FP16 进行硬件级加速。

### 阶段三：SAHI 大图切片与微米级标定 (Advanced SMT Inspection)
1. 在质检模块中集成 SAHI 切片滑窗算法逻辑；
2. 引入标定板（Checkerboard）像素-毫米转换系数计算，支持直接输出真实物理尺寸偏差。

### 阶段四：端到端产线闭环与 OEE 决策联动
1. 人体工步节拍数据直通 MES 模块，实时计算各工位平衡率（Line Balancing Rate）；
2. SMT 缺陷率联动贴片机参数补偿，形成自动化闭环纠偏。
