# 第一部分：快速入门（操作员指南）

> 本部分面向**生产线操作员**和**车间管理员**，无需技术背景。
> 按照步骤操作即可完成"施教"和"训练"。

---

## 1. 系统入口

登录系统后，在左侧导航菜单中会看到三个相关页面：

| 菜单名称 | 用途 |
|---------|------|
| **视频学习** | 录制/上传标准操作视频，让系统自动学习操作步骤 |
| **视频训练** | 用学习到的数据训练专属 AI 模型 |
| **训练评估** | 对比不同版本模型的效果 |

> **权限说明**：所有登录用户可以**查看**数据；上传、学习、训练等操作需要**管理员**及以上权限。

## 2. 怎样施教——让系统学会你的操作

> "施教"就是：你按照标准流程做一遍，系统通过摄像头/视频学习你的动作。
> 就像教一个新员工——你在前面做，他在后面看。

### 2.1 第一步：上传操作视频

1. 点击左侧菜单 **"视频学习"**
2. 点击右上角 **"上传视频模板"** 按钮
3. 在弹出的窗口中填写：

| 填写项 | 怎么填 | 示例 |
|-------|--------|------|
| **模板名称** | 给这个操作起个名字 | SMT贴片标准操作 |
| **业务类型** | 选择最匹配的类型 | 组装 / 焊接 / 检测 / 包装 / 自定义 |
| **描述** | （选填）补充说明 | 第三工位标准贴片流程 |
| **工位编号** | （选填）你的工位号 | station_smt_01 |
| **视频文件** | 选择一个录制好的视频文件 | 支持 MP4、AVI 等常见格式 |

4. 点击 **"确定"** 提交

> **提示**：视频最好在正常工作环境下拍摄，光线充足，操作动作清晰完整。

### 2.2 第二步：进入学习工作台

1. 上传成功后，列表中会出现新的一条记录
2. 点击该记录右侧的 **"工作台"** 按钮
3. 工作台分为左右两栏：
   - **左侧**：模板信息和参数配置
   - **右侧**：学习结果展示

### 2.3 第三步：配置学习参数

在左侧 **"学习配置"** 卡片中：

| 参数 | 含义 | 推荐设置 |
|-----|------|---------|
| **学习模式** | 动作+物体 = 同时学操作动作和识别物品 | 动作 + 物体学习 |
| **采样间隔** | 每隔几帧分析一次 | 5（数值越小分析越细，但更慢） |
| **最低置信度** | 低于此分数的检测结果会被忽略 | 0.4 |
| **场景变化阈值** | 画面变化多大算是一个新步骤 | 30 |
| **关注对象类别** | 想让系统重点识别哪些物品 | 如：screwdriver, product, hand |
| **物体模型** | （选填）使用自定义物体检测模型 | 首次施教不用选 |
| **动作模型** | （选填）使用自定义动作识别模型 | 首次施教不用选 |

> **首次施教**：使用默认参数即可，不需要选择自定义模型。

### 2.4 第四步：启动学习

1. 点击左侧的 **"保存"** 按钮保存配置
2. 点击 **"学习"** 按钮，系统开始后台分析
3. 分析过程中会显示 **进度条**
4. 等待状态变为 **"已完成"**（绿色标签）

> **注意**：分析可能需要几分钟到十几分钟，取决于视频长度。

### 2.5 第五步：查看学习结果

学习完成后，右侧面板会出现丰富的分析结果：

#### 🎬 视频回放区

- 可以 **播放视频**，画面上自动显示：
  - **矩形框**：标注检测到的物体（如螺丝刀、面板）
  - **骨骼线**：标注操作人员的手部动作轨迹
- 上方显示当前是 **第几步**，动作名称是什么
- 可以切换"显示目标框"、"显示骨骼"

#### 📊 统计概览

- 检测到了多少种物体
- 识别出了多少个动作
- 处理了多少帧画面

#### 📋 七个结果标签页

| 标签 | 内容 | 你可以做什么 |
|-----|------|------------|
| **动作时间轴** | 按时间顺序列出每个操作步骤 | 点击某步骤跳转到视频对应位置；编辑步骤名称；拆分或合并步骤 |
| **智能建议** | 系统给出的改进建议 | 点击"采纳建议"接受推荐 |
| **姿态学习结果** | 每个步骤的手部运动数据 | 查看手腕位移等专业数据 |
| **物体学习结果** | 物品出现的频率统计 | 查看每种工具/零件被使用的次数 |
| **模板对比** | 与其他模板对比差异 | 选择另一个模板，查看区别 |
| **SOP 预览** | 自动生成的标准作业指导书 | 预览自动生成的操作步骤文档 |
| **关键帧** | 每个步骤的代表性画面 | 查看截图 |

#### ✏️ 人工修正

系统自动识别不一定完全准确，你可以修正：

1. 在 **"动作时间轴"** 中点击某个步骤的 **"编辑"** 按钮
2. 修改：
   - **动作名称**：改成你习惯叫的名字
   - **描述**：补充说明
   - **保留为标准动作**：勾选表示这个步骤是标准操作的一部分
3. 也可以 **"拆分"**（把一个步骤分成两个）或 **"并入前一段"**（合并两个步骤）

> **关键操作**：仔细检查每个步骤的名称是否准确，这直接影响后续训练质量。

## 3. 怎样训练——用学到的数据训练专属模型

> "训练"就是：用施教学到的数据，让 AI 专门学会你们车间的操作。
> 就像新员工看了一遍之后开始练习——练得越多越熟练。

### 3.1 准备工作（只需做一次）

进入左侧菜单 **"视频训练"** 页面。

#### 创建物体类别

1. 切换到 **"物体类别"** 标签页
2. 点击 **"新建物体类别"**
3. 填写：

| 填写项 | 怎么填 | 示例 |
|-------|--------|------|
| **类别编码** | 英文缩写 | hand |
| **显示名称** | 中文名称 | 手部 |
| **描述** | 补充说明 | 操作人员手部 |
| **颜色** | 标注颜色 | #1677ff（默认蓝色即可） |

4. 重复以上步骤，把所有需要识别的物品都创建好

#### 创建动作类别和样本集

1. 切换到 **"动作样本"** 标签页
2. 在 **动作类别** 区域创建动作类别（如"拿取零件"、"放置零件"）
3. 点击 **"新建动作样本集"** 创建一个样本集（相当于一个训练数据文件夹）

### 3.2 从施教结果导入数据

这是把"施教"和"训练"连接起来的关键步骤：

1. 在 **"动作样本"** 标签页中找到 **"从学习会话导入"** 卡片
2. 选择 **模板**（你之前施教用的那个）
3. 点击 **"载入默认会话"**，系统自动找到该模板的学习结果
4. 选择 **会话**（如果多次学习过，选最好的一次）
5. 选择 **目标样本集**（刚才创建的样本集）
6. 选择 **动作类别**（这批数据属于哪个动作）
7. 点击 **"导入会话动作"**

> **提示**：可以多次施教、多次导入，数据越多训练效果越好。

### 3.3 创建训练任务

目前训练任务的创建通过系统自动完成。当数据准备就绪后：

1. 在 **"训练任务"** 标签页中查看训练任务列表
2. 系统会自动开始训练，状态从 **"等待中"** → **"运行中"** → **"已完成"**
3. 如果状态变为 **"失败"**（红色标签），请联系管理员排查

### 3.4 查看训练详情

1. 在训练任务列表中点击 **"查看详情"**
2. 右侧弹出详情面板，可以看到：

| 信息卡片 | 内容 |
|---------|------|
| **基础信息** | 任务名称、状态、训练轮数、图片尺寸、精度、推理速度 |
| **训练产物** | 训练产出的模型文件，可以 **下载** |
| **训练日志摘要** | 日志行数、尾部内容预览；可以点击 **"查看完整日志"** |
| **数据集摘要** | 标注数量、包含的类别列表 |
| **状态时间线** | 创建时间、开始时间、完成时间 |

### 3.5 激活模型（部署上线）

训练完成后：

1. 在训练任务列表中，已完成的任务旁边会出现 **"激活模型"** 按钮
2. 点击后，该模型成为当前使用的模型
3. 激活后回到 **"视频学习"** 的学习配置中就能选择这个模型了

> **重要**：激活新模型会替换当前使用的同类模型。建议先在"训练评估"中对比确认效果。

## 4. 怎样评估——对比不同模型的表现

进入左侧菜单 **"训练评估"** 页面。

### 4.1 查看模型概览

页面顶部显示四个统计数字：

| 统计 | 含义 |
|-----|------|
| **模型总数** | 已训练的模型数量 |
| **活跃模型** | 当前正在使用的模型数量 |
| **最佳精度** | 所有模型中最高的准确率 |
| **最快推理** | 所有模型中推理速度最快的 |

### 4.2 查看模型历史

下方的 **"模型历史版本"** 表格列出所有训练过的模型，包括：
- 模型名称
- 当前是否为活跃版本
- 精度、mAP@50 等指标
- 训练数据量

### 4.3 对比两个模型

1. 在顶部选择 **模型类型**（物体模型 或 动作模型）
2. 选择 **两个模型**（最多选两个）
3. 点击 **"对比所选模型"**
4. 系统会展示：
   - **基础对比**：两个模型的基本指标差异
   - **类别指标对比图**：按具体类别显示精确率、召回率的差异柱状图
   - **类别明细表**：每个类别的详细数据

## 5. 完整闭环流程图

```
┌──────────────────────────────────────────────────────────────────────┐
│                          完整使用流程                                  │
└──────────────────────────────────────────────────────────────────────┘

  ① 施教（视频学习）          ② 准备训练数据           ③ 训练
  ─────────────────         ───────────────         ─────────
  上传操作视频 ─────→        定义物体类别  ─────→     训练任务
       │                    定义动作类别               自动执行
  配置学习参数               创建样本集                   │
       │                        │                  产出模型
  点击"学习" ──────→    从学习会话导入数据 ─────→          │
       │                        │                       │
  查看结果              数据越多效果越好                   │
  修正动作名称                                              │
  采纳建议 ───────────────────────────────────────────────┘
                                                           │
  ④ 评估                    ⑤ 部署                  ⑥ 增强
  ──────                   ─────                   ──────
  对比模型效果 ←────    激活最佳模型  ←─────    回到施教使用新模型
  确认精度达标            模型上线部署              学习效果更准确
```

> **核心思路**：施教 → 训练 → 评估 → 激活 → 再次施教（用更好的模型），形成持续改进的闭环。

## 6. 常见问题

### Q：施教后看不到结果？

**A**：检查模板状态是否已变为"已完成"（绿色）。如果显示"分析中"（蓝色），请等待。如果显示"失败"（红色），请检查视频文件是否正常。

### Q：训练任务一直显示"等待中"？

**A**：确保已完成数据导入（从学习会话导入了足够的样本）。联系管理员确认训练服务是否正常运行。

### Q：激活模型后效果没有变好？

**A**：可能原因：
- 训练数据太少（建议每种动作/物体至少有 5 个以上样本）
- 视频质量不佳（光线不足、动作不清晰）
- 尝试调整学习参数（降低采样间隔、调整置信度阈值）

### Q：可以同时使用多个模型吗？

**A**：每种类型（物体检测 / 动作识别）同时只能激活一个模型。但你可以在训练评估页面保留所有历史版本，随时切换。

### Q：一个视频模板可以学习多次吗？

**A**：可以。每次学习会生成一个新的"学习会话"，你可以保留多次学习的结果，选择最好的一次用于训练。

### Q：动作步骤划分不准确怎么办？

**A**：在工作台的"动作时间轴"标签页中：
- 点击 **"编辑"** 修改步骤名称和描述
- 点击 **"拆分"** 把一个步骤分成两个
- 点击 **"并入前一段"** 把两个步骤合并
- 也可以调整学习配置中的 **"场景变化阈值"** 后重新学习

## 7. 系统架构概览

```
┌─────────────────────────────────────────────────────────────────┐
│  前端 (React 19 + Vite + Ant Design)                            │
│  ├─ /video-learning        视频学习页                             │
│  ├─ /video-training        自定义训练工作台                        │
│  └─ /video-training/evaluation  训练评估中心                      │
└────────────────────────────┬────────────────────────────────────┘
                             │ HTTP REST
┌────────────────────────────▼────────────────────────────────────┐
│  后端 (FastAPI + SQLAlchemy 2.0 async + PostgreSQL)              │
│  ├─ /api/video-learning/*   学习模块 API                         │
│  ├─ /api/video-training/*   训练模块 API                         │
│  └─ /api/models/*           模型管理 API                         │
└────────────────────────────┬────────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────────┐
│  AI 推理层                                                       │
│  ├─ YOLO 物体检测 (Ultralytics)                                  │
│  ├─ 骨骼提取 (YOLO-Pose)                                        │
│  ├─ 自定义物体模型 (custom_object)                                │
│  └─ 动作分类器 (centroid-based prototype matching)                │
└─────────────────────────────────────────────────────────────────┘
```

**端口**：前端 3260 / 后端 3265

## 9. 数据模型与关系

```
VideoTemplate (视频模板)
  ├── learning_config       学习参数配置 (JSON)
  ├── sop_content           SOP 内容 (JSON)
  ├── workflow_summary      流程摘要 (JSON)
  │
  ├── 1:N → LearningSession (学习会话)
  │         ├── object_model_id    关联的物体模型
  │         ├── action_model_id    关联的动作模型
  │         ├── analysis_result    分析结果 (JSON)
  │         │
  │         ├── 1:N → ActionSequence (动作序列)
  │         │         ├── user_defined_name  用户自定义名
  │         │         ├── is_kept            保留为标准动作
  │         │         ├── features           特征数据 (JSON)
  │         │         └── objects_in_scene   场景物体 (JSON)
  │         │
  │         └── 1:N → KeyFrame (关键帧)
  │                   ├── detections       检测结果 (JSON)
  │                   └── is_action_boundary
  │
ObjectCategory → ObjectAnnotationSet → ObjectAnnotation
ActionCategory → ActionSampleSet → ActionSample

TrainingJob (训练任务)
  ├── job_type        object_detection / action_recognition
  ├── dataset_type    object_annotation_set / action_sample_set
  ├── model_id → Model (训练产出)
  ├── config_json     训练配置
  ├── metrics_json    训练指标
  ├── log_path        日志路径
  └── status          pending → running → completed/failed

Model (模型)
  ├── model_type      custom_object / custom_action
  ├── accuracy / precision / recall / map50 / map50_95
  ├── inference_speed  推理速度 (ms)
  └── is_active       当前是否激活
```

## 10. 训练数据链路

### 10.1 物体检测训练链路

```
ObjectCategory (定义类别)
    ↓
ObjectAnnotationSet (标注集)
    ↓
ObjectAnnotation (每帧标注: image_path + bbox + class)
    ↓
TrainingJob (job_type=object_detection)
    ↓ 导出 YOLO 格式数据集 → Ultralytics 训练
Model (model_type=custom_object)
    ↓ 激活
视频学习配置 → 使用自定义物体模型重新分析
```

### 10.2 动作识别训练链路

```
视频学习 → LearningSession → ActionSequence (含骨骼特征)
    ↓ from-session 导入
ActionSampleSet → ActionSample (COCO17 骨骼序列 JSON)
    ↓
TrainingJob (job_type=action_recognition)
    ↓ centroid prototype 匹配训练
Model (model_type=custom_action, JSON 格式)
    ↓ 激活
视频学习配置 → 使用自定义动作模型重新分析
```

### 10.3 完整闭环

```
施教 → 学习会话 → 动作/物体数据
    ↓
训练 → 自定义模型 → 激活
    ↓
再次施教（使用更好的模型）→ 更精准的分析结果
    ↓
继续训练 → 模型迭代升级
```
