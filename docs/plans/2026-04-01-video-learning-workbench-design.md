# Video Learning Workbench Design

**目标**: 将现有视频学习页面升级为可配置、可预览、可分段、可学习动作与物体的工作台。

**现状问题**:
- 前端只有模板列表、上传、启动学习、详情查看，缺少工作台交互。
- 后端动作识别仅基于场景变化与检测对象聚合，缺少骨骼学习配置和物体关注类别配置。
- 动作段无法人工修正命名，也无法直观看到关键帧与分段结果。

**设计原则**:
- 在现有 `video_learning` 链路上渐进增强，不推翻当前模型与数据表。
- 第一阶段优先交付“可用工作台”，支持骨骼动作学习 + 物体学习 + 分段预览。
- 以 YOLO 检测和 YOLO pose 为基础，不引入新的重型训练框架。

## 功能设计

1. 模板管理增强
- 上传视频模板时允许配置学习模式、采样参数、分段方式、关注对象类别。
- 模板支持保存默认学习参数，便于重复学习。

2. 学习工作台
- 左侧: 视频信息、学习参数、启动学习。
- 中间: 分段时间轴与关键帧预览。
- 右侧: 动作段列表、动作命名、关注物体统计。

3. 动作学习
- 使用 YOLO pose 提取骨骼关键点。
- 通过采样帧上的骨骼统计特征 + 场景变化划分动作段。
- 每段输出动作名称建议、置信度、时间范围、关键帧。

4. 物体学习
- 使用 YOLO detect 识别目标对象（手、螺丝刀、产品等）。
- 支持模板级“关注类别”配置。
- 输出每段对象出现频率、共现关系、主对象。

5. 人工校正
- 支持修改动作段名称、备注、是否保留为标准动作。
- 支持按时间轴人工合并/拆分动作段（第一阶段先做名称编辑和保留标记，拆分合并第二阶段再做）。

## 数据设计

- `VideoTemplate` 增加默认学习配置字段。
- `LearningSession` 增加学习模式、采样配置、关注对象类别快照。
- `ActionSequence.features` 中补充骨骼统计特征与对象特征。
- `KeyFrame.detections` 保持现有结构，扩展支持 pose keypoints。

## 接口设计

- 新增模板学习配置更新接口。
- 新增学习摘要详情接口，返回动作段、关键帧、对象统计。
- 新增动作段编辑接口（改名、备注、保留标记）。

## 前端设计

- 将 `VideoLearning` 重构为工作台式页面：
  - 模板列表区
  - 学习参数抽屉/侧栏
  - 学习结果详情页签（概览/时间轴/动作段/关键帧/对象统计）
- 增加参数表单：采样间隔、最小置信度、场景阈值、学习模式、关注对象类别。
- 增加关键帧时间轴和动作段表格。

## 风险与边界

- 第一阶段不做真正训练型动作分类器，仅做“模板学习+特征抽取+人工命名”。
- 第一阶段不做浏览器端视频逐帧标注。
- 若 YOLO pose 模型加载失败，页面应明确提示并退化为物体学习模式。
